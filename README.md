# NixOS Configuration

This repository contains my personal NixOS configuration, managed with Nix flakes and Home Manager.

## Features

*   **NixOS Flakes**: Modern way to manage NixOS configurations, ensuring reproducibility and easy updates.
*   **Home Manager**: Manage user-specific configurations (dotfiles, packages) declaratively.
*   **Secure Boot with Lanzaboote**: Secure boot setup using Lanzaboote.
*   **KDE Plasma 6**: Desktop environment.
*   **NVIDIA Prime Reverse Sync**: Configuration for NVIDIA graphics with reverse sync.
*   **Bluetooth**: Enabled with experimental features and auto-enable policy.
*   **Fonts**: Sarasa Gothic, Noto Nerd Fonts, Liberation, Fira Code.
*   **Input Method**: Fcitx5 with Chinese addons and Nord theme.
*   **Flatpak**: Enabled for easy application management.
*   **Containerization**: Podman with Docker compatibility and `podman-compose`.
*   **Full Disk Encryption**: Configuration for BitLocker encrypted Windows partition and VM images.
*   **WinApps**: Integration for running Windows applications.
*   **System Packages**: Essential tools like `git`, `sbctl`, `cryptsetup`, `kdePackages`, `wayland-utils`, `wl-clipboard`, `xclip`, `kdiff3`, `freerdp`, `hardinfo2`, `dive`, `podman-tui`, `podman-compose`, `vlc`, `keepassxc`, `git-credential-keepassxc`, `uv`.
*   **User Packages**: `tree`.
*   **Programs**: Firefox, Vim.

## Structure

*   `flake.nix`: Defines the NixOS system and Home Manager configurations using flakes.
*   `configuration.nix`: Main NixOS system configuration.
*   `home.nix`: Home Manager configuration for user `u`.
*   `hardware-configuration.nix`: Hardware-specific configuration generated by NixOS installer.
*   `nixos-label-suffix.nix`: Custom NixOS label suffix.
*   `kernel/modules/nvidia.nix`: NVIDIA kernel module configuration.

## Installation

If you don't have Nix flakes enabled globally, you can enable them temporarily by adding the following to /etc/nix/nix.conf:

```conf
experimental-features = nix-command flakes
```

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/ttimasdf/nixos-config.git
    cd nixos-config
    ```
2.  **Apply the configuration**:
    ```bash
    sudo nixos-rebuild switch --flake .#Nokia-N97
    ```
    (Replace `Nokia-N97` with your desired hostname if different).

## Updating

To update the flake inputs to their latest revisions:
```bash
nix flake update
```

To rebuild the system after changes:
```bash
