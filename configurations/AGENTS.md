# configurations/

## OVERVIEW
Host, Home Manager, and system-level user configurations. Auto-discovered by nixos-unified and `myusers.nix`.

## STRUCTURE
```
configurations/
├── nixos/<host>/              # → nixosConfigurations.<host>
│   ├── configuration.nix      # Entry: imports hardware-configuration.nix
│   └── hardware-configuration.nix
├── home/<user>/               # → legacyPackages.${system}.homeConfigurations.<user>
│   └── default.nix            # Entry: auto-imports all other .nix in user dir
└── users/<user>.nix           # System-level user config (groups, perms)
                                # Loaded by myusers.nix automatically
```

## WHERE TO LOOK

| Task | Location | Notes |
|------|----------|-------|
| Host NixOS config | `configurations/nixos/<host>/configuration.nix` | Imports `./hardware-configuration.nix` |
| Hardware config | `configurations/nixos/<host>/hardware-configuration.nix` | Generated by `nixos-generate-config` |
| User home config | `configurations/home/<user>/default.nix` | Auto-imports sibling .nix files in user dir |
| System user config | `configurations/users/<user>.nix` | Groups, shell, extraGroups, etc. |
| Common modules (cross-platform) | `configurations/nixos/common/` | Shared between nixos and nix-darwin |

## CONVENTIONS

### Host Config Signature
```nix
{ flake, config, lib, pkgs, ... }:
let inherit (flake.inputs) self; in
{ imports = [ ./hardware-configuration.nix ]; ... }
```

### User Config Pattern
```nix
# configurations/home/<user>/default.nix
{ flake, config, lib, pkgs, ... }:
let inherit (flake.inputs) self private-module; in
{
  imports = [
    # Auto-import all sibling .nix files in user dir
    (with builtins; map (fn: ./${fn}) (filter (fn: fn != "default.nix") (attrNames (readDir ./.))))
    ++ [ self.homeModules.all private-module.homeModules.all ];
  ];

  rabit.home.me = {
    username = "<user>";
    fullname = "Full Name";
    email = "email@example.com";
  };
}
```

### User Auto-Discovery
`modules/nixos/common/myusers.nix` discovers users from `configurations/home/` listing.
- Each `configurations/home/<user>.nix` or `configurations/home/<user>/default.nix` → user auto-registered
- Corresponding `configurations/users/<user>.nix` loaded for system-level user config
- Manual override: set `rabit.nixos.myusers` explicitly

## ANTI-PATTERNS

- **NEVER put NixOS-specific config in `configurations/nixos/common/`** - shared with nix-darwin
- **NEVER change bootloader UUID** after initial install (viscacha:508, MNIX:501)
- **Do NOT modify `hardware-configuration.nix`** manually (unless intentionally) - regenerated by nixos-generate-config
